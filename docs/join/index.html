Private circle invitation

Open this link on an iPhone with Big Beautiful Restaurant Log installed.

The invitation is a twelve-character join code, kept after the # in the link so it is never sent to this website.

If tapping the link did nothing, you do not need it. Open the app, go to More → Manage, and type the code into Got a join code? — the person who invited you can simply read it out.

A code works once and expires after seven days.
